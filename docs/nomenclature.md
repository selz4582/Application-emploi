# Nomenclature de l’application

## Nom retenu : Carnet Emploi 42

Le nom **Carnet Emploi 42** décrit un outil personnel de suivi de recherche d’emploi :

- **Carnet** indique que les données et décisions appartiennent à l’utilisateur ;
- **Emploi** décrit directement la finalité de l’application ;
- **42** rappelle que les recherches sont orientées vers le département de la Loire.

Ce nom évite de présenter l’application comme le site ou le service d’un organisme
institutionnel. L’interface emploie donc un vocabulaire personnel : « mon espace »,
« mes offres », « mes CV » et « mon profil ».

## Règles d’écriture

- Nom complet dans le titre de la fenêtre et au démarrage : **Carnet Emploi 42**.
- Nom court dans l’en-tête : **Carnet Emploi**.
- Nom technique des nouvelles sauvegardes : `carnet-emploi-42-AAAAMMJJ-HHMMSS.zip`.
- Les anciennes archives, quel que soit leur nom, restent détectées et restaurables dès
  lors qu’elles sont des fichiers ZIP valides.
